MCP Server

一行配置，让 Claude / Cursor / Cline 用上判决库

配置示例：
# mcp.json · Claude Desktop / Cursor / Cline
{
  "mcpServers": {
    "wenshucha": {
      "type": "http",
      "url": "https://api.wenshucha.com/mcp",
      "headers": { "Authorization": "Bearer YOUR_KEY" }
    }
  }
}

接入后即可在对话中调用 search_cases、get_case_full_text、list_relevant_statutes、quantify_outcome 等工具，答案自带案号回链。
